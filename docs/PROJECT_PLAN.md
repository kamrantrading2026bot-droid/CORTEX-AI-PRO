
# CORTEX AI PRO

Advanced AI Trading Assistant for Android Chrome.

## Project Goal

Build a mobile-friendly AI trading assistant with a floating control panel, real market data analysis, and authorized demo trade execution.

## Main Features

1. Floating AI Button
2. Trading Control Dashboard
3. Currency Pair Selection
4. OTC and Regular Market Selection
5. Trading Duration Selection
6. Trade Amount Selection
7. Live Market Data Collector
8. Candlestick Analysis
9. RSI and Momentum Analysis
10. Support and Resistance Detection
11. CALL / PUT / NO TRADE Signals
12. Confidence Calibration
13. Demo Trading Integration
14. Trade History and P/L
15. Emergency Stop

## Technology Stack

- Android: Kotlin
- Dashboard: React
- Backend: Python and FastAPI
- Data Processing: NumPy and Pandas
- Database: SQLite
- Version Control: GitHub

## Important Requirements

- Never generate random trading signals.
- Use real and verified market data.
- Display NO TRADE when data is insufficient.
- Never claim a trade was placed without confirmation.
- Protect account credentials and API keys.
- Use authorized platform integrations only.
- Test with demo funds before any live trading.
