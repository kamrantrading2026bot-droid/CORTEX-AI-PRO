CORTEX-AI-PRO

Advanced AI Trading Assistant for Android Chrome

CORTEX-AI-PRO is a project to build a mobile-friendly trading analysis dashboard that uses verified market data and technical analysis to generate transparent trading signals.

Main Features

- Floating Android control panel
- Currency pair selection
- OTC and Regular market selection
- Multiple candle timeframes
- Live market data analysis
- Candlestick and price action analysis
- RSI, momentum, and trend analysis
- Support and resistance detection
- CALL / PUT / NO TRADE signals
- Confidence estimates
- Demo trading integration (authorized access only)
- Trade history and performance tracking
- Emergency stop and risk controls

Technology

- Android: Kotlin
- Dashboard: React
- Backend: Python and FastAPI
- Data analysis: NumPy and Pandas
- Database: SQLite

Safety and Reliability

- No random or fabricated signals
- No guaranteed profits or accuracy claims
- NO TRADE when market data is insufficient
- No trade is reported as placed without confirmation
- Platform integrations must be authorized
- Demo testing before live trading

Development Status

Current stage: Project foundation

Market data integration and demo trade execution are not yet implemented.
